# BiazziTech AI Studio — plugin do Antigravity

Painel lateral (Sidecar) do BiazziTech AI Studio dentro do Google Antigravity, mais o servidor MCP `biazzitech`.

- **Painel:** chat de código e lore com rodízio entre provedores de IA, imagens e pixel art, páginas de quadrinho,
  fichas de personagem e exportação para o Godot — sem gastar tokens do chat do Antigravity.
- **Proxy compatível com OpenAI:** `http://localhost:9090/v1/chat/completions` (ou a porta escolhida na instalação).
- **MCP:** ferramentas `studio_code`, `studio_text`, `free_image_create`, `pixai_image_create` e `ai_providers_status`.

Este plugin é instalado pelo `instalar_motores.ps1` na raiz do repositório. Veja o README principal para tudo o mais.
