# Como contribuir

Obrigado pelo interesse! Issues com bugs, ideias e pull requests são bem-vindos.

## Acordo de contribuição (obrigatório)

O BiazziTech AI Studio é distribuído sob a AGPL-3.0 e **também** pode ser licenciado comercialmente pelo autor.
Para que isso continue possível, toda contribuição precisa deste acordo:

> Ao enviar um pull request, patch ou qualquer outra contribuição para este projeto, declaro que:
>
> 1. A contribuição é obra minha (ou tenho o direito de enviá-la) e não contém código de terceiros com licença incompatível.
> 2. Licencio a contribuição sob a AGPL-3.0 **e** concedo a BiazziTech (Fausto Sousa) uma licença perpétua, mundial,
>    gratuita, irrevogável e não exclusiva para usar, modificar, sublicenciar e distribuir a contribuição sob
>    quaisquer outros termos, inclusive comerciais e de código fechado.
> 3. Continuo dono dos direitos autorais da minha contribuição.

Escreva no pull request: **"Li e concordo com o acordo de contribuição do CONTRIBUTING.md."**
Pull requests sem essa frase não podem ser aceitos.

## Dicas

- Nunca inclua chaves de API, tokens ou dados pessoais no código, nos exemplos ou nos prints.
- Mantenha o projeto sem dependências obrigatórias além do Python padrão (a `pypdf` é opcional).
- Textos da interface e da documentação em português do Brasil.
